# Smart-building energy forecasting experiments

This project evaluates XGBoost, Random Forest, LSTM, Transformer, and a hybrid CNN-LSTM-Attention model using the UCI Appliances Energy Prediction dataset (ID 374).

## Dataset and provenance

Official page: https://archive.ics.uci.edu/dataset/374/appliances-energy-prediction
Dataset DOI: https://doi.org/10.24432/C5VC8G
Original dataset paper: Candanedo, L. M., Feldheim, V., & Deramaix, D. (2017). Data driven prediction models of energy use of appliances in a low-energy house. *Energy and Buildings*, 140, 81–97.

The dataset contains 19,735 observations at 10-minute intervals. The target `Appliances` is appliance energy use in Wh. `lights` is lighting energy use in Wh; it is not occupancy ground truth. This dataset does not establish a live IoT deployment by the present authors.

## Run

```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
pip install -r requirements.txt
python run_experiments.py
```

The script fetches the dataset through `ucimlrepo`. If the API download fails, download `energydata_complete.csv` from the official UCI page and place it in `data/energydata_complete.csv`.

## Outputs

`outputs/model_metrics.csv`, `outputs/test_predictions.csv`, charts, SHAP feature importance, and `experiment_metadata.json`.

## Methodological notes

- Time-ordered 70/15/15 train/validation/test split.
- Predictor clipping bounds and standardization are learned on training data only.
- Lag/rolling target features use only prior target observations.
- High target values are not deleted automatically as outliers.
- MAPE uses a denominator floor of 1 Wh and is reported as `MAPE_floor1_pct`.
- Results must be run and checked before they are inserted into a publication. Do not report outputs that have not been generated by this script.
- The script's SHAP analysis explains XGBoost, not necessarily the test-best model. If the final manuscript claims SHAP for the selected best model, implement the corresponding model-specific explainer and explain that model instead.
